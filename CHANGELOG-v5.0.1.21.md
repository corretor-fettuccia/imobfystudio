# Imobify Studio 5.0.1.21

## Floating Container Pro v1.1.0
- Novo botão **Como usar** no inspetor do componente.
- Popup contextual gera exemplos usando o ID público real da instância selecionada.
- Exemplo pronto para campo de destino/CTA, `href`, `data-floating-open` e `window.ImobifyFloating.open()`.
- Botões para copiar cada exemplo.
- Diagnóstico inteligente dos blocos atualmente capturados pelo container.
- Alerta quando `Quantidade de itens internos` não corresponde aos blocos disponíveis.
- Resumo do grid desktop/tablet/mobile e dos modos de abertura configurados.
- Popup de ajuda responsivo e utilizável também em telas estreitas.

## Plugin SDK / Editor
- Novo metadado opcional `inspectorGuide` em manifestos Plugin Play.
- O editor usa `inspectorGuide.kind` para oferecer ajuda especializada sem misturar instruções estáticas à lista de campos.
