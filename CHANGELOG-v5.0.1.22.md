# Imobify Studio 5.0.1.22

- Floating Container Pro atualizado para v1.2.0.
- Fluxo oficial de implantação simplificado: qualquer botão abre o container usando somente `href="#floating-box-..."`.
- Novo tipo de campo Plugin Play `computed`, autodeclarado no `plugin.json`, com template, texto de apoio e botão copiar.
- Floating Container Pro declara no próprio manifesto o campo “HREF para abrir este container”.
- `inspectorGuide` agora é autodeclarado como `href-container`, com os nomes das props usados para ID, quantidade de filhos, colunas e modos responsivos.
- Popup “Como usar” prioriza apenas o HREF e não exige JavaScript nem atributos extras.
- Runtime reconhece HREFs de Floating Container antes do smooth-scroll de âncoras normais.
- API JavaScript preservada apenas para compatibilidade e integrações internas.
