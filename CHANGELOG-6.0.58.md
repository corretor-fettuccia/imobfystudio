# ImobStudio 6.0.58 — Coreografias combinadas

- Biblioteca superior com seis coreografias completas: Cinematográfica, Editorial em Camadas, Dinâmica Alternada, Arquitetônica 3D, Cascata Orgânica, Impacto Sofisticado.
- Aplicar uma combinação configura automaticamente os elementos da section, com ordem, duração, delay e intervalo.
- Criar e salvar coreografias personalizadas por nome; reutilizar, atualizar pelo nome e excluir através do modal.
- Presets personalizados persistem neste navegador via localStorage; ao aplicar na section, a configuração é salva no projeto JSON e incorporada no HTML exportado.
- Preview completo no modal e no iframe da página via mesmo runtime de efeitos da exportação.
- Mantidos gatilhos de visibilidade da section e controles existentes.
- Diretório raiz e identificação da interface atualizados para 6.0.58.

**Limitação:** biblioteca personalizada é local ao navegador; exportar o JSON do projeto preserva a coreografia aplicada à section, mas não exporta automaticamente toda a biblioteca de presets personalizados.
