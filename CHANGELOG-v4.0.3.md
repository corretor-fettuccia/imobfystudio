# Imobify Studio 4.1.0

## Perfil Visual global
- Tokens globais para cores de títulos, textos e textos sobre superfícies escuras.
- Controle de fontes, peso, tamanhos H1/H2/H3, corpo, line-height e tracking.
- Controle de largura do container, espaçamento de seções, gaps e padding de componentes.
- `core/design-system.css` é carregado após os estilos dos plugins para compatibilidade global.
- Plugins nativos/bundled recebem ponte semântica de tipografia, cor e composição.
- Plugin Play futuro herda tipografia e tokens de composição por padrão.
- Presets e modelos agora carregam a matriz completa de identidade visual.
