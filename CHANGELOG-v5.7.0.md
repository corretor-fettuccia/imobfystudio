# Imobify Studio 5.7.0

Atualização editorial e tipográfica dos plugins de texto.

## Magazine Text Pro 1.2.0
- tipografia completa para olho editorial, título, subtítulo, lead, corpo e citação;
- famílias tipográficas independentes para títulos e corpo;
- alinhamento de cabeçalho e corpo, incluindo texto justificado;
- alinhamento do bloco e padding desktop/mobile com precisão fracionária;
- escala tipográfica mobile;
- presets cinematográficos: Cinema suave, Foco/blur, Subida elegante, Reveal por máscara e Profundidade editorial;
- animações leves via IntersectionObserver e respeito a `prefers-reduced-motion`.

## Only TEXT — Context 1.1.0
- alinhamento justificado aprimorado com hifenização;
- alinhamento independente do bloco;
- padding e espaçamentos com precisão de 0,25 px;
- controles adicionais de entrelinha e tracking para subtítulo, lide e corpo;
- mesmos presets cinematográficos do Magazine Text Pro;
- efeitos ativados somente quando o runtime está pronto, evitando conteúdo invisível caso o JavaScript falhe.
