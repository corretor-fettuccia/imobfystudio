# Imobify Studio 3.0.0

## Editor visual

- inserção de seções diretamente entre blocos;
- arrastar e soltar para reordenar;
- duplicar, ocultar, excluir e mover;
- transição configurável por seção;
- blocos reutilizáveis;
- rolagem contínua ou encaixe suave.

## Produção em massa

- biblioteca persistente de projetos com IndexedDB;
- novo projeto por modelo;
- duplicação de landing pages;
- dados globais aplicados em SEO, conteúdo, contato e formulários;
- exportação de todos os projetos em lote;
- modelos para lançamento, terreno e construção, investimento e oferta rápida.

## Componentes

- novo slider imobiliário responsivo;
- Plugin Play v3 com múltiplos arquivos CSS e JavaScript ordenados;
- Form.v4 restaurado com os quatro arquivos originais preservados;
- adaptador não invasivo para configurar o Form.v4 pelo inspetor.
