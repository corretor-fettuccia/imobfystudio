# Pacotes Plugin Play — Imobify Studio 5.2.3

Arquivos prontos para instalar em **Estrutura → Plugin Play**:

- `anti-ia-copy-policy-v1.0.0.zip`: política de proteção contra cópia/automação;
- `button-single-v1.0.0.zip`: botão único para CTA e navegação;
- `flip-card-pro.zip`: Flip Card 3D Single v4.4;
- `ar-card-popout-3d-single-v1.2.0.zip`: AR Card Popout 3D Single;
- `flipcard-3d-video-single-v1.1.0.zip`: Flip Card 3D Video Single;
- `form-sender-v4.zip`: Form.v4 preservado e integrado por adaptador;
- `gallery-big-four.zip`: Galeria Big Four v2.2;
- `image-single-v1.0.0.zip`: imagem responsiva individual;
- `location.zip`: Google Maps + endereço + proximidades `tempo | ponto`;
- `property-slider.zip`: slider imobiliário responsivo;
- `whatsapp-flutuante-pro-v1.1.0.zip`: WhatsApp flutuante Pro com foto no hover por URL ou arquivo local/Base64;
- `plugin-starter.zip`: estrutura mínima para novos componentes.

A suíte `tests/plugin-play.test.cjs` percorre automaticamente todos os ZIPs desta pasta usando o parser real do Plugin Play. Se um pacote ficar incompatível, o teste falha antes da distribuição.
