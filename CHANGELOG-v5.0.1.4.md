# Imobify Studio 5.0.1.4 — timeline Scrollytelling

- Scrollytelling Vídeo Pro atualizado para v2.3.0.
- Timeline visual de chaves e cards no Inspector.
- Snap por frame com FPS configurável (24/25/30/50/60).
- Arraste de playhead, chave, bloco e borda final com commit somente ao soltar.
- Reprodução cinematográfica de avanço usa `video.play()` + `playbackRate` variável, evitando seeks sucessivos durante a transição.
- Bridge antigo v4 é desconectado ao carregar o editor v5.
- Caminhos de projetos antigos migram para `plugins/scrollytelling-video-pro-v2.3.0/`.
- Plugins persistidos mais antigos continuam impedidos de sobrescrever a versão bundled mais nova.
