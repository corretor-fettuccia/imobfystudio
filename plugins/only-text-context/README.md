# Only TEXT — Context 1.2.1

Tipografia editorial com alinhamento independente, padding preciso, motion cinematográfico e **composição balanceada de linhas**.

O modo Balanceado preserva o espaçamento natural entre palavras, evita hifenização automática e usa `text-wrap: balance/pretty` conforme o tipo de texto. Não expande palavras como o justificado tradicional.
