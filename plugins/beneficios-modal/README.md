# Benefícios + Modal 1.1.1

Componente para benefícios, infraestrutura e diferenciais de empreendimentos.

- Itens ilimitados gerenciados no Inspetor do Imobify Studio 5.11.1+.
- Seletor visual Font Awesome com campo manual para classes futuras/personalizadas.
- Grade responsiva: padrão de 5 itens por linha no desktop e 3 no mobile.
- **Perfil da vitrine** independente, com paletas Assinatura, Marfim, Mineral, Floresta, Monocromática e Personalizada.
- **Perfil do modal** independente, com paletas Obsidian, Ivory, Forest, Midnight, Mineral e Personalizada.
- Contraste automático do modal: ao trocar o fundo, título, descrição, botão fechar e ícone escolhem automaticamente uma cor clara ou escura com leitura adequada; o cálculo usa a cor efetiva do modal, inclusive ajustes manuais sobre um perfil.
- As cores manuais têm prioridade por atributo: você pode manter um Perfil do modal/vitrine e alterar apenas o fundo, borda, destaque ou ícone sem o perfil sobrescrever o ajuste.
- Modal acessível com `<dialog>`, foco, ESC, botão fechar e clique no backdrop opcional.
- Conteúdo detalhado renderizado diretamente no HTML publicado para SEO e descoberta por IA.
- Cores, tipografia, borda, profundidade dos ícones, animação e alinhamento configuráveis.
- O menu “Estado do componente” e “Salvar bloco” do Studio preservam itens, perfis e estilos como preset reutilizável.
