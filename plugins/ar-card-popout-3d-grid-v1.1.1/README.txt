AR Card Popout 3D Grid v1.1.0

Plugin Play para Imobify Studio / Framework 5.x.

- Até 4 cards no mesmo componente
- Card 1 sempre visível; Cards 2–4 opcionais
- 1–4 colunas no desktop
- Até 2 colunas em tablet
- 1 coluna no mobile

- Dimensões e comportamento 3D compartilhados para manter unidade visual
- Compatível com Perfil Visual e Ocultar no mobile
