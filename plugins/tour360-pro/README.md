# Tour 360 Pro 3.2.0

Plugin section para Imobify Studio 5.12.4.

- configuração completa no modal Tour 360 Studio;
- cenas e hotspots armazenados em `props.tourConfig`;
- publicação responsiva com toque/pinça;
- branding e menu de pontos com zona segura;
- imagens locais do JSON interno são extraídas pelo compilador do Studio.


## Integração 3.2.1
O editor avançado faz parte do próprio pacote Plugin Play. Ao instalar o ZIP no Imobify Studio 5.12.4, a section expõe o editor em modal sem depender de uma pasta externa copiada manualmente.


## v3.2.6 — Branding fiel à configuração
- `enabled` é a chave mestra de exibição.
- A posição selecionada é preservada; o branding não troca de canto automaticamente.
- Controles e menu cedem espaço ao branding.
- Branding vazio não aparece.
- Remover imagem não desabilita texto/link.


## v3.2.6
- Menu de spots recolhível por botão hambúrguer de 3 linhas.
- O painel fecha ao selecionar um spot ou clicar fora.
- Branding no mesmo canto do menu é alinhado na mesma linha, ao lado, sem sobreposição.
