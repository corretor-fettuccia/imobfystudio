# Tour 360 Editor v3.2.6

## Alteração desta versão
- No menu de spots, hotspots do tipo **Informação** agora centralizam a câmera no `yaw/pitch` do próprio hotspot antes de exibir a informação.
- O zoom atual é preservado durante esse foco.
- O painel de spots é recolhido imediatamente ao selecionar um item.
- Clique direto no hotspot dentro da panorâmica mantém o comportamento anterior.

## Regra de não regressão
Todos os comportamentos consolidados das versões anteriores permanecem válidos.
