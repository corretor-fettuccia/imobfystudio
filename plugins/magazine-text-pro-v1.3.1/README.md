# Magazine Text Pro 1.3.1

Tipografia editorial avançada com alinhamento, padding preciso, motion cinematográfico e **composição balanceada de linhas**.

O modo Balanceado preserva palavras inteiras e o espaçamento natural entre elas: títulos e chamadas usam `text-wrap: balance`, enquanto corpos longos usam `text-wrap: pretty`, sem hifenização automática.
