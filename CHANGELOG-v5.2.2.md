# Imobify Studio 5.2.2

## Plugins nativos removidos
- Removido o plugin nativo `Menu fixo` (`sticky-nav`).
- Removido o plugin nativo `WhatsApp flutuante` (`floating-whatsapp`).
- Projetos JSON antigos que ainda listem esses comportamentos têm esses IDs descartados na importação.
- Os plugins Pro permanecem disponíveis normalmente.

## WhatsApp flutuante Pro 1.1.0
- Novo campo **Foto no hover**.
- Aceita URL de imagem ou arquivo local pelo seletor de mídia do Imobify.
- Arquivos locais podem ficar incorporados como `data:image/...;base64,...`.
- No hover ou foco do botão, a foto substitui visualmente o ícone do WhatsApp.
- Sem foto configurada, o comportamento visual anterior é preservado.
